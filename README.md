# Бот-помощник «Код Женщины»

Телеграм-бот от лица помощника Юлии Курицыной. Отвечает нейросетью в тоне бренда и ведёт к записи.

## Что умеет

| Кнопка | Что происходит |
|---|---|
| 🌿 Разобраться в запросе | Бережный диалог: бот отражает чувство, задаёт по одному вопросу, показывает, что может стоять за запросом глубже (род, тело, сценарии). После 3–4 сообщений мягко предлагает экспресс-сессию. |
| 🃏 Послание дня | Случайный образ метафорической карты, толкование, вопрос дня и практика на 2–3 минуты. Одно послание на человека в день. |
| 💎 Услуги и цены | Готовый текст из `services.md` (нейросеть цены не выдумывает). |
| ✍️ Записаться | Анкета: имя → запрос → формат → удобное время → контакт. Заявка сразу приходит Юлии в Телеграм и сохраняется в `bot.db`. |
| 📢 Канал | Ссылка на канал «Код Женщины». |

Можно и просто писать боту, без кнопок: он ответит как в режиме «Разобраться в запросе».

Защита:
- на посторонние темы бот вежливо отказывает;
- не ставит диагнозов и не делает расстановок или раскладов в чате;
- на сообщения о мыслях о самоубийстве сразу даёт телефоны экстренной помощи, без нейросети;
- на одного человека не больше 30 сообщений нейросети в день, чтобы не расходовать ключ.

Команды:
- `/myid` — узнать номер чата;
- `/stats` — статистика (только для Юлии);
- `/cancel` — отменить запись.

## Запуск: 4 шага

**1. Создать бота.** В Телеграме открыть @BotFather → `/newbot` → придумать название, например «Код Женщины — помощник», и имя пользователя, оканчивающееся на `bot`. BotFather пришлёт токен. Там же через `/setuserpic` можно поставить аватар, а через `/setdescription` — описание.

**2. Заполнить настройки.** Скопировать `.env.example` в файл `.env` и вписать:
- `BOT_TOKEN` — токен из шага 1;
- `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` — адрес API, ключ и модель вашего провайдера нейросети.

Проверить ключ:

```
.venv\Scripts\python check_llm.py --models
.venv\Scripts\python check_llm.py
```

Первая команда покажет список моделей, вторая — пробный ответ.

**3. Запустить.** Дважды щёлкнуть `run.bat`. Пока окно открыто, бот работает.

**4. Подключить заявки.** Юлия пишет боту `/myid` → число вписать в `ADMIN_CHAT_ID` в `.env` → перезапустить бот. Теперь заявки приходят ей в личку.

## Что править без программиста

- `services.md` — услуги и цены (то, что видит человек по кнопке). Разметка: `<b>жирный</b>`, `<i>курсив</i>`.
- `knowledge.md` — что нейросеть знает о Юлии и её методе.
- Тексты приветствия и правила общения — в `prompts.py`.

После правки — перезапустить бот.

## Чтобы бот работал круглосуточно

### Бесплатно: Bothost.ru

На бесплатном тарифе бот загружается только из репозитория GitHub. Загрузка архивом доступна лишь на платных тарифах.

1. **GitHub.** Зарегистрироваться на github.com → «New repository» → имя, например `kod-zhenshchiny-bot`, тип **Public** → «Create repository».
2. Нажать «uploading an existing file» и перетащить **все файлы из папки `bot_для_GitHub`** (не из `bot`! В `bot` лежит `.env` с ключами) → «Commit changes».
3. **Bothost.** Зарегистрироваться на bothost.ru → создать бота:
   - платформа — Telegram;
   - библиотека — aiogram;
   - токен — от @BotFather;
   - Git URL — адрес репозитория из шага 1;
   - ветка — `main`.
4. В разделе «Переменные окружения» бота добавить `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, а после `/myid` — ещё `ADMIN_CHAT_ID`. Затем перезапустить или передеплоить бота.
5. Логи смотреть в дашборде Bothost. Заявки хранятся в `/app/data/bot.db` и не стираются при обновлениях.

Как обновить бота (цены, тексты): поправить файл на GitHub (карандаш → «Commit changes») → в Bothost нажать «Обновить» или «Передеплоить».

Не запускайте бота одновременно на компьютере (`run.bat`) и на Bothost — Телеграм выдаст ошибку конфликта.

### Платно и надёжнее: свой сервер

На домашнем компьютере бот спит, когда спит компьютер. Самый простой и дешёвый вариант — виртуальный сервер (VPS) в России: Timeweb Cloud, Beget, Selectel. Хватит самого маленького тарифа на Ubuntu, это примерно 150–300 ₽ в месяц.

На сервере:

```bash
sudo apt update && sudo apt install -y python3-venv
# скопировать папку bot (без .venv и bot.db) в /opt/kod-bot, затем:
cd /opt/kod-bot && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

Автозапуск — файл `/etc/systemd/system/kod-bot.service`:

```ini
[Unit]
Description=Kod Zhenshchiny bot
After=network-online.target

[Service]
WorkingDirectory=/opt/kod-bot
ExecStart=/opt/kod-bot/.venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now kod-bot
journalctl -u kod-bot -f   # смотреть журнал
```

Важно: один и тот же бот нельзя запускать одновременно на компьютере и на сервере — Телеграм выдаст ошибку конфликта.
